## Rebuilding for the production root

Use the committed `v2-dev` release source with Node.js 24, then run:

```sh
npm ci
npm run check
env -u PAGES_BASE_PATH -u NEXT_PUBLIC_BASE_PATH -u NEXT_PUBLIC_CALENDAR_AGENDA_URL npm run build
node scripts/package-hostgator-release.mjs /tmp/laaw-life-release.tar.gz
```

Use a new archive filename for each release. Builds fetch current public
calendar data, so a later build's generated timestamps and archive hash will
differ. The archive hash above identifies the original deployed artifact.

Commit and push every production change before uploading its output files.

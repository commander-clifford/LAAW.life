# Version 2.0.0 — September 16, 2026

This record accompanies [Version 2.0.0](https://github.com/commander-clifford/LAAW.life/releases/tag/v2.0.0),
the release following `v1.0.0`.

## Included behavior

- The Option 4 daily card shows the current Pacific day and readable event
  details above each location's full Google Calendar.
- The location drawer and saved preference let visitors return to Ivy Station
  or Hawthorne. The home redirect preserves campaign query parameters.
- Production pages include the verified free GA4 integration. Local and Pages
  previews are excluded from collection; `/og/` remains uninstrumented.
- The original page is preserved byte-for-byte. Missing routes return the
  branded recovery page with HTTP 404.
- The production calendar workflow targets a refresh every 30 minutes using
  public Google feeds and a restricted FTPS account. A real scheduled run has
  passed generation, upload, and public verification.
